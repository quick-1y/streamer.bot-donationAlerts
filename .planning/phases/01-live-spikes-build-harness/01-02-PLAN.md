  <action>
Complete `unpack_bytes(raw, max_bytes=MAX_DECODED_BYTES)` with these rules, each failure raising SbFormatError with a short reason:
- reject `len(raw) > MAX_INPUT_BYTES`;
- strip ASCII whitespace, then `base64.b64decode(..., validate=True)` (binascii.Error means invalid base64);
- require the first 4 bytes to equal MAGIC;
- `d = zlib.decompressobj(31)`; `out = d.decompress(payload[4:], max_bytes + 1)`. Reject when `len(out) > max_bytes` or `d.unconsumed_tail` is non-empty (over the cap), when `not d.eof` (truncated), and when `d.unused_data` is non-empty (trailing data after the gzip member);
- reject an output that starts with the UTF-8 BOM bytes EF BB BF;
- reject invalid UTF-8 (strict decode).
`read_sb(path)` checks `path.stat().st_size <= MAX_INPUT_BYTES` before reading. Never parse with anything but `json.loads`.

Implement `structural_findings(model, json_bytes)`, returning HARD lines of the form `HARD check:<name> <json path>: <reason>` for these checks:
- `roundtrip`: `dump(json.loads(json_bytes)) == json_bytes`;
- `utf8-no-bom`;
- `ids-format`: every value under a key named exactly `id` is a str matching GUID_RE and is not NULL_GUID;
- `ids-unique`;
- `refs-resolve`: every other str value that matches GUID_RE as a whole string equals some id in the file or NULL_GUID. This is generic: it relies on no key names, which stay unknown until the golden (assumption A4);
- `bytecode-utf8`: every `byteCode` value decodes via decode_bytecode.
Add subcommand `check <file>`. It prints `PASS check:<name>` or `FAIL check:<name>` per check, followed by the HARD lines, then `check: <n> failed`. It returns 0 when clean, 1 on findings, 2 on SbFormatError.

Implement `diff_ids(model_a, model_b)`. Key objects by `action:<name>`, `queue:<name>`, `sub:<action name>#<position>` (position in the action's subActions list, depth-first for nested `subActions`) and `trigger:<action name>#<position>`. Emit `SAME <key>`, `CHANGED <key> <id_a> -> <id_b>`, `ONLY-A <key>`, `ONLY-B <key>`, then `diff-ids: same=<n> changed=<n> only_a=<n> only_b=<n>`. Add subcommand `diff-ids <a> <b>`, which returns 0 (informational) or 2 on a format error.

Add tests for every behavior bullet. Build payloads directly with gzip/base64 in the tests: an exact-cap payload with `max_bytes=len(json_bytes)`, the same payload with `max_bytes=len(json_bytes) - 1`, gzip bytes plus `b"x"`, a gzip stream cut in half, magic `b"XXXX"`, a BOM-prefixed JSON. Check CLI return codes through `build_sb.main([...])`.

## Trust Boundaries

| User-exported / third-party `.sb` to build_sb.py | Untrusted file content (base64, gzip, JSON) enters the tools |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
